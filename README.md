# 🐍 Python Beginner Projects

A collection of beginner-friendly Python projects focusing on logic building, user interaction, and core programming concepts.

---

## 📌 About This Repository

This repository contains multiple **beginner-level Python projects** created to strengthen fundamentals such as:

* Conditional statements
* Loops
* User input handling
* Basic use of Python standard libraries

Each project is written in a **simple, readable, and beginner-friendly** manner.

---

## 📂 Projects Included

1. **Guess The Number**
   A number guessing game where the user tries to guess a randomly generated number.

2. **Simple Calculator**
   Performs basic arithmetic operations like addition, subtraction, multiplication, and division.

3. **Even–Odd Checker**
   Checks whether a given number is even or odd.

4. **Simple Interest Calculator**
   Calculates simple interest and total payable amount based on user input.

5. **Temperature Converter**
   Converts temperature between Celsius, Fahrenheit, and Kelvin.

6. **Multiplication Table Generator**
   Generates a multiplication table for a given number.

7. **Dice Rolling Simulator**
   Simulates rolling a dice using random number generation.

8. **Password Generator (Basic)**
   Generates a random password using letters and digits.

   ```bash
   git clone https://github.com/your-username/your-repo-name.git
   ```
3. Navigate to the project folder.
4. Run any file using:

   ```bash
   python filename.py
   ```
